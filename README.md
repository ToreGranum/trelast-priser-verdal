# Trelastpriser Verdal

Moderne prissammenligning for trelast hos:

- OBS BYGG Verdal
- Bygger'n Verdal
- XL-BYGG Skogn

## Status

Nettsiden er lagt inn med eksempeldata. Neste steg er å koble butikkspesifikke datakilder/scrapere til prisdatabasen og kjøre oppdatering automatisk hver time.

## Pris per meter

`data/prices.json` er datakilden som nettsiden leser. Når scraperen oppdaterer denne filen, vises de nye prisene automatisk på siden.
